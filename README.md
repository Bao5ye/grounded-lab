# 扎根 · Grounded Lab

轻量的 Windows 本地研究工作台，帮助研究者开展程序化扎根理论编码，并在研究者控制下调用远程模型辅助编码、复核和理论整合。

> 首次打开的是虚构学习项目。AI 生成结果是候选解释，需要研究者回到原始材料逐项核验；本工具不能自动证明理论饱和。

## 主要功能

- 新建和切换项目，填写研究意图；导入或粘贴 TXT、Markdown、CSV、TSV 文本。
- 人工添加、修订和确认概念，管理范畴、子范畴、证据、关系、替代解释、核心范畴、理论故事线、备忘录和理论抽样。
- 可选调用兼容 OpenAI Chat Completions 协议的远程模型，按角色分阶段生成开放编码、主轴编码及选择性编码建议；另可复核现有编码或生成候选理论。
- 校验 AI 建议的证据标识和逐字引文，提示未产生有效编码的片段。文字匹配不等于解释正确。
- 导出 CSV 编码表、HTML 报告和单项目 JSON 备份，并从 JSON 恢复项目。

## 使用

下载仓库 ZIP 并完整解压，在 Windows 上双击 **扎根理论工作台.exe**。需要 Microsoft Edge 或 Google Chrome 以及 .NET Framework 4.5 或更新版本。使用期间保留本地服务窗口。应用监听 `127.0.0.1:48328`，只在本机提供页面。

用户数据保存在程序目录的“用户数据”，默认下载到“导出成果”。定期导出 JSON 并独立备份，恢复会替换当前项目。仓库使用 `.gitignore` 排除本地数据、临时文件、导出成果和常见密钥文件。

AI 模式需自行填写兼容接口的 HTTPS 完整地址、模型名及 API Key。每次调用前确认资料发送和潜在费用；密钥仅保存在当前窗口内存。人工模式不调用远程服务。只有在有权提供资料给对应服务商时才启用 AI，必要时先脱敏。

详见 [使用说明](使用说明.md) 和 [系统设计与功能说明](系统设计与功能说明.md)。

## 构建与测试

源码包括 `dist/` 下的静态界面和 `启动器.cs`。Windows 上运行：

```powershell
.\build.ps1
```

构建使用 Windows 自带的 .NET Framework C# 编译器，产生 `扎根理论工作台.exe`；不需要 Electron。若要运行测试，需另行安装 Node.js，然后执行：

```powershell
node --test tests/*.test.js
```

## 边界

PDF、DOCX、图片、音视频仅登记文件信息，不保存原始二进制文件或自动解析；可以先转为文本再导入。CSV/TSV 按纯文本读取。无离线模型、团队同步和断点续跑。AI 任务单次最多 100 个片段、100,000 字符，服务商模型的实际上下文限制可能更低。模型可能漏编码、产生不可靠关系或返回不兼容格式，请查看运行记录并人工核验。

自动化测试覆盖数据约束和模拟模型工作流；真实模型成功响应及不同服务商的兼容性需要使用有效密钥进一步验证。
